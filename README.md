# Asfak Rahman H — Portfolio

A responsive personal portfolio for **Asfak Rahman H**, a Computer Science student and aspiring full-stack developer based in Chennai, India. The site presents selected projects, technical skills, education and experience, certifications, a résumé, and contact links in a clean, editorial-style interface.

## Highlights

- Responsive layouts for desktop, tablet, and mobile
- Sticky navigation with active-section highlighting and a mobile menu
- Animated hero roles, statistics, scroll progress, and section reveals
- Interactive project cards, credential glow effects, and magnetic buttons
- Dedicated sections for projects, about, journey, certificates, and contact
- Downloadable résumé and direct GitHub, LinkedIn, email, and phone links
- Accessible skip navigation and reduced-motion support
- No frameworks, package installation, or build step required

## Built With

- **HTML5** — semantic page structure and content
- **CSS3** — custom properties, responsive grids, transitions, and animation
- **Vanilla JavaScript** — navigation, observers, typing effects, and interactions
- **Google Fonts** — DM Sans, DM Mono, and Playfair Display

## Run Locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/Asfak0077/asfak-rahman-portfolio.git
cd asfak-rahman-portfolio
open index.html
```

Alternatively, serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

- Update portfolio copy, projects, credentials, and contact details in `index.html`.
- Adjust colors, typography, spacing, and breakpoints in `styles.css`.
- Change hero roles and interaction behavior in `script.js`.
- Replace the portrait and résumé in `assets/` while keeping the existing file names, or update their references in `index.html`.

## Deployment

Because this is a static site, it can be hosted directly on GitHub Pages, Netlify, Vercel, or any static web host. For GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, and save.
